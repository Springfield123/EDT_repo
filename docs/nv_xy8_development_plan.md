# NV XY8 presentation-impact development plan

## Communication objective

Show that EDT is a calibration-aware diagnostic for a finite control regime: the best XY8 depth is set by the balance among filter response, coherence, pulse fidelity, and timing overhead, rather than by a universal low-depth rule.

## Work package 1: canonicalize and regenerate

**Implementation**

- Treat `code/plotting/make_fig_xy8_qre.py` as the only sweep and figure implementation.
- Retain `scripts/make_fig_xy8_qre.py` only as a compatibility entry point that executes the canonical script.
- Use `python code/run_reproduction_pipeline.py --nv-only` to regenerate the nominal paper figure, all three scenario records, processed CSV/JSON files, robustness artifacts, and `Fig5_source_data.csv`.
- Record the scenario label, configuration digest, target frequency, sweep grid, and pulse-count convention in generated artifacts.

**Acceptance criteria**

- Old and new entry points produce the same result.
- `outputs/reproduced_figures`, `data/processed`, and Figure 5 source data report the same nominal optimum and configuration digest.

## Work package 2: make the finite regime visible

**Implementation**

- Replace the off-resonant line plot with `log10(eta / eta_best)` over pulse spacing and XY8 block count.
- Mark the best point, the heuristic `N=16` point, and the high-depth `N=64` point.
- Compare the best block count across the conservative, nominal, and optimistic hardware scenarios.

**Acceptance criteria**

- The optimum remains visible despite the many-orders-of-magnitude off-resonant penalty.
- The figure states that lower sensitivity-proxy values are better.
- The scenario comparison reproduces best block counts `8`, `20`, and `64`.

## Work package 3: explain the mechanism with ablations

**Implementation**

- Starting from the nominal scenario, separately set per-pulse fidelity to one, make coherence effectively lossless, and remove initialization/readout/dead-time overhead.
- Plot the normalized sensitivity penalty versus block count at the primary resonance and the resulting best block count for each ablation.
- Mark optima that reach the tested sweep boundary.

**Acceptance criteria**

- Every curve is generated by the canonical sweep.
- The figure makes clear which physical cost limits control depth.
- CSV and JSON data accompany the rendered figure.

## Work package 4: map hardware uncertainty to control choice

**Implementation**

- Sweep per-pulse fidelity from `0.992` to `1.000` and nominal-coherence scale from `0.5` to `2.0`.
- Plot the best XY8 block count as a phase diagram and mark the nominal calibration.
- Export every evaluated point with its best spacing, depth, sensitivity proxy, and boundary status.

**Acceptance criteria**

- The plot supports the statement: "given measured hardware quality, EDT selects the appropriate control depth."
- Boundary optima are machine-readable and cannot be presented as resolved interior optima.

## Work package 5: quantify the finite operating window

**Implementation**

- Define the EDT window as all sampled controls with `eta <= 1.10 eta_best`.
- Draw its contour on the normalized heatmap and export every accepted point.
- Record whether the window reaches a sampled boundary.

**Acceptance criteria**

- The nominal optimum lies inside the exported window.
- Window bounds agree across CSV and JSON artifacts.
- The contour is labeled explicitly as "within 10% of best."

## Work package 6: test frequency portability

**Implementation**

- Sweep target frequency from 50 to 500 kHz.
- Compare the selected pulse spacing with the primary-resonance prediction `tau = 1/(4f)`.
- Plot the optimum and 10% depth window across the band.

**Acceptance criteria**

- Every frequency uses the canonical sweep and includes the exact primary resonance.
- Boundary status and the full frequency table are exported.

## Work package 7: propagate calibration uncertainty

**Implementation**

- Draw seeded Monte Carlo samples for pulse fidelity, coherence, contrast, photon rate, and timing overhead.
- Export each draw, its optimum, and the empirical optimum-depth distribution.
- Minimize the 95th-percentile sample-wise regret to select a robust control and compare it with the nominal optimum.

**Acceptance criteria**

- The random seed and all sampling assumptions are stored with the results.
- Repeated runs with the same seed reproduce identical samples and optima.
- The robust choice has no larger 95th-percentile regret than the nominal choice.

## Work package 8: bound the alternative-sequence claim

**Implementation**

- Compare XY8, XY4, and CPMG at equal total pi-pulse count using the existing instantaneous-pulse, scalar-fidelity model.
- Export sequence block counts and the shared equal-pulse prediction.

**Acceptance criteria**

- The output states that pulse phase and axis errors are unresolved.
- Coincident predictions are presented as a model-capability check, not evidence that the sequences are physically equivalent.

## Work package 9: expose the resource--performance frontier

**Implementation**

- Minimize sensitivity proxy and total pi-pulse count simultaneously.
- Flag dominated controls and the Pareto-efficient depths.
- Highlight the performance optimum, the fewest-pulse point within 10%, and the `N=16` engineering compromise.

**Acceptance criteria**

- Every depth uses its best pulse spacing from the canonical sweep.
- `N=16` reports 20% fewer pulses than `N=20` for about a 1% sensitivity penalty.
- Depths beyond the nominal optimum are identified as dominated when they use more pulses and perform worse.

## Work package 10: pre-register a minimal validation set

**Implementation**

- Freeze six resonant depths (`N=8,10,16,20,32,64`) and one model-selected off-resonance timing control.
- Export predicted sensitivity, sequence cost, deterministic rank, and seeded 95% calibration intervals.
- Leave measurement, standard-error, repeat-count, and pass/fail columns blank until data collection.
- Hash the calibration, canonical model source, and predictive protocol.

**Acceptance criteria**

- All seven controls reproduce exact points from the canonical sweep.
- The off-resonance timing is selected by a recorded rule rather than by hand.
- `N=20` is ranked first and receives additional recommended repeats.
- Five validation criteria remain machine-readable and pending until measurements are entered.

## Work package 11: convert hardware measurements into a control decision

**Implementation**

- Map target frequency, pulse fidelity, and `T2_1` to resonant spacing, optimal depth, total pulse count, 10% window, lower-cost alternative, and predicted sensitivity.
- Add optional seeded input-uncertainty propagation with modal and 95th-percentile robust choices.
- Emit explicit warnings for extrapolation, boundary optima/windows, multimodal recommendations, and nominal resource assumptions.
- Replace the continuous phase-diagram scale with categorical shallow, moderate, deep, very-deep, and unresolved regions.
- Overlay scenario projections, a pulse-fidelity improvement arrow, and the selected nominal recommendation.

**Acceptance criteria**

- Nominal inputs return `tau=1.25 us`, `N=20`, a `N=10-32` window, and `N=16` as the lower-cost alternative.
- Every phase-grid point reproduces direct recommender results without categorical interpolation.
- CLI JSON, phase-figure annotations, and robustness summary share a recommendation digest.
- Fixed uncertainty seeds reproduce identical modal and robust choices.

## Work package 12: claim-level tests

The paper-pipeline tests verify:

1. Exact 1.25 and 3.75 microsecond resonances are present at 200 kHz.
2. Tau-grid refinement does not move the nominal optimum.
3. `N` means XY8 blocks and `N_pi = 8 N` everywhere in the paper pipeline.
4. The three scenario fixtures reproduce best block counts `8`, `20`, and `64`.
5. Generated CSV, JSON, and Figure 5 source data share one configuration and optimum.
6. The 10% window is interior and contains the nominal optimum.
7. The frequency sweep tracks the exact primary resonance.
8. Monte Carlo sampling is deterministic for a fixed seed and robust selection cannot worsen its target quantile.
9. Alternative sequences are compared at equal total pulse count, with the current model limitation explicit.
10. Pareto-efficient and dominated depths obey the two-objective dominance definition.
11. Prospective validation predictions reproduce canonical points, expected ranks, pulse counts, durations, and configuration digests.
12. Hardware recommendations reproduce the phase grid, frequency scaling, boundary warnings, uncertainty decisions, and cross-artifact annotations.

pytest -q tests/test_xy8_paper_pipeline.py
